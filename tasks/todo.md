# Vinicunca docs hub task list

## Current implementation state

- The seven-package Nuxt shell, package-specific tabs, and active-section sidebars are in place. The UnoCSS config remains removed at the user's request; visual review follows its replacement.
- Tagged Markdown source mappings and a one-package sync command now cover ESLint Config, UnoCSS Preset, and UnoCSS Variants. Their existing guides were copied into their owning repositories, but are not in a release tag yet, so the hub retains its current pages.
- The docs release workflow accepts manual or repository dispatches, imports one tagged package, records its commit, builds, and deploys. Source workflows dispatch after tags/releases when `DOCS_DISPATCH_TOKEN` is configured in those repositories.
- The copied ESLint guide now states the current peer range and composer config name. The UnoCSS Preset fluid guides and demos use the current slash syntax, options, and utility inventory; the UnoCSS Variants install guide no longer asks for ESLint and its demo frontmatter parses. These corrections are present both in the hub and the owning repositories.
- The Perkakas HTML endpoint and raw Markdown route now share one cached metadata transform. `/raw/perkakas/functions.md` expands all documented function signatures, examples, parameters, returns, categories, and source links from the current metadata file. The metadata file still needs to come from a tagged Perkakas release.
- Perkakas tag imports now clone the exact tag, install that checkout, generate TypeDoc JSON from `src/index.ts`, pin source links to the resolved commit, and lock its digest. Only a Perkakas dispatch runs TypeDoc; other package imports reuse the committed JSON. Its release workflow now dispatches after a successful release when `DOCS_DISPATCH_TOKEN` exists.
- Akar now owns initial Markdown and a `vue-component-meta` generator. The hub seeds 65 component reference pages from `v2.0.20` metadata (393 public components), exposes per-component JSON, and will regenerate only Akar content on a future tag dispatch. The Dialog guide records its pinned Reka UI source and license. The first new tag is needed before the importer can lock these authored docs.
- Pohon's 181 generated source pages, eight generated section landing pages, and 124 main component metadata records are seeded in the hub. A Pohon tag import is wired to run only Pohon's docs generation, append tagged props/slots/events, and lock all outputs; component JSON is available per name. The first new tag containing `scripts/docs-meta.mjs` is needed to exercise this in CI.
- Taman now imports a source-owned public landing page plus the `taman-core`, `taman-ui`, and `request` READMEs. A `docs-v*` tag dispatches a one-package import; internal plans are excluded. The first docs tag is needed for a locked Taman import.
- The lockfile now resolves Pohon UI 2.0.1. Three exact-version exceptions for historical transitive packages allow pnpm's `no-downgrade` policy to verify the rest of the lockfile. Frozen installation, Nuxt typechecking, and static generation of 1,409 routes pass. The local Pohon theme overrides were updated for the `modal` names in Pohon UI 2.0.1. Nuxt Icon now serves a bounded set of locally installed collections during generation, with no missing-icon warnings. Static output includes 520 `.json` API files for Perkakas, Akar, and Pohon.
- A `wrangler.jsonc` and Cloudflare migration note are ready for review. The current Firebase deployment step is still active; no Cloudflare project or domain has been changed.
