## addIndex

No direct Perkakas helper. Use the notes below, or native JavaScript.

_Not provided by Perkakas._

You don't need `addIndex` In Perkakas because all functions that iterate over
arrays or objects have their callbacks in the format that `addIndex` returns by
default. If you still have a use-case that isn't possible via Perkakas please open
an issue at the Perkakas GitHub project.

```ts
// Ramda
addIndex(map)((val, idx) => `${idx}-${val}`, DATA);

// Perkakas
map(DATA, (val, idx) => `${idx}-${val}`);
```

## append

Ramda `append` → [`concat`](/perkakas/functions#concat).

_Not provided by Perkakas._

- You can replicate this function via the native JS spread `...` operator or via
  the Perkakas `concat` function (by wrapping the operand with an array).
- There might be cases where building an `append` function could be more
  efficient than using the suggested alternatives, but we believe they are
  extremely rare. If you want to suggest adding it reach out to us at the Perkakas
  GitHub project.

```ts
// Ramda
append(operand, DATA);

// Or curried
const addsAbc = append(operand);

// Perkakas
concat(DATA, [operand]);

// Or in a pipe
pipe(DATA, concat([operand]));

// Native
[...DATA, operand];

const addsAbc = <T extends ReadonlyArray<unknown>>(data: T) => [...data, operand];
```

## complement

Ramda `complement` → [`isNot`](/perkakas/functions#isNot).

- Unlike Ramda's `complement`, `isNot` preserves type predicates: negating a
  type-guard returns a type-guard which _excludes_ the guarded type, so the
  result of [`filter`](/perkakas/functions#filter) stays narrowed.
- Ramda's `complement` preserves the arity of the function it wraps, and the
  result stays curried. `isNot` only takes a single-parameter predicate and
  passes just the first argument through; wrap multi-parameter functions with
  the native [logical NOT operator `!`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_NOT)
  instead.
- Ramda's `complement` negates the _truthiness_ of any return value, whereas
  `isNot` requires a predicate that returns a `boolean`. Compose with
  [`isTruthy`](/perkakas/functions#isTruthy) to get the Ramda semantics.

#### Predicates

```ts
// Ramda
complement(predicate);

// Perkakas
isNot(predicate);
```

#### Filtering

```ts
// Ramda
filter(complement(is(String)), DATA);

// Perkakas
filter(DATA, isNot(isString));
```

#### Multiple parameters

```ts
// Ramda
complement(isGreaterThan);

// Native
(a: number, b: number) => !isGreaterThan(a, b);
```

#### Non-boolean predicates

```ts
// Ramda
complement(getLength);

// Perkakas
isNot(piped(getLength, isTruthy));

// Or directly via Native JS:
(data: string) => !getLength(data);
```

## defaultTo

Ramda `defaultTo` → [`defaultTo`](/perkakas/functions#defaultTo).

- `Number.NaN` is not considered nullish and would not result in returning the
  default value. Use [`when`](/perkakas/functions#when) with the built-in [`Number.isNaN`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/isNaN)
  and a [`constant`](/perkakas/functions#constant) for the fallback value.
- Unlike in Perkakas, Ramda allows the fallback value to be of any type, even
  those that are incompatible with the data type. It also allows the data type
  to be non-nullish; for those cases use the built-in [Nullish coalescing operator `??`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Nullish_coalescing)
  directly, or use [`when`](/perkakas/functions#when) with [`isNullish`](/perkakas/functions#isNullish) and
  [`constant`](/perkakas/functions#constant).

#### Nullish

```ts
const DATA: number | undefined | null;

// Ramda
R.defaultTo(456)(DATA);

// Perkakas
defaultTo(DATA, 456);
```

#### NaN

```ts
const DATA = Number.NaN;

// Ramda
R.defaultTo(10)(DATA);

// Perkakas
when(DATA, Number.isNaN, constant(10));
```

#### Both

```ts
const DATA: number | null | undefined;

// Ramda
R.defaultTo(10)(DATA);

// Perkakas
when(
  DATA,
  (x) => x === undefined || x === null || Number.isNaN(x),
  constant(10),
);
```

#### Non-matching fallback

```ts
const DATA: string | null | undefined;

// Ramda
R.defaultTo(123)(DATA);

// Perkakas
when(DATA, isNullish, constant(123));

// or natively
DATA ?? 123;
```

## flatten

Ramda `flatten` → [`flat`](/perkakas/functions#flat).

Unlike `flatten` in Ramda, the Perkakas `flat` function is always bound by the
`depth` param. To replicate the Ramda behavior use a high, **const** value.
`Infinity` and `Number.MAX_INTEGER` are not consts and would result in
inefficient typing.

```ts
// Ramda
flatten(DATA);

// Perkakas
flat(DATA, 100); // ✅
flat(DATA, Infinity); // ❌
```

## hasIn

Ramda `hasIn` → [`hasProp`](/perkakas/functions#hasProp).

- Ramda's `hasIn` uses [the `in` operator](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/in)
  which returns `true` for **inherited** properties. Perkakas uses
  [`Object.hasOwn`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/hasOwn)
  which ignores them.

#### Own properties

```ts
// Ramda
hasIn('a', obj);

// Perkakas
hasProp(obj, 'a');
```

#### Inherited properties

```ts
// Ramda
hasIn('toString', {}); // => true

// Perkakas
hasProp({}, 'toString'); // => false
```

## ifElse

Ramda `ifElse` → [`when`](/perkakas/functions#when).

- Perkakas supports both if-like statements, and if-else-like statements (which is
  what Ramda's ifElse function supports); The former is done by using a
  predicate function and a mapper function, and the latter is done by wrapping
  both mappers with an object.
- To support extra arguments Ramda requires one of the functions provided to
  provide full typing to all params, in Perkakas this isn't needed as the extra
  arguments would be inferred from the call site.

#### if-else

```ts
// Ramda
ifElse(predicate, onTrue, onFalse)(data);

// Perkakas
when(data, predicate, { onTrue, onFalse });

// Or in a pipe
pipe(data, when(predicate, { onTrue, onFalse }));
```

#### if

```ts
ifElse(predicate, onTrue, identity)(data);

// Perkakas
when(data, predicate, onTrue);

// Or in a pipe
pipe(data, when(predicate, onTrue));
```

#### extra args

```ts
// Ramda
const mapper = ifElse(
  (x: string | undefined, index: number) => x === undefined,
  (_, index) => `item_${index}`,
  identity,
);
map(data, mapper);

// Perkakas
map(
  data,
  when(
    (x) => x === undefined,
    (_, index) => `item_${index}`,
  ),
);
```

## includes

Ramda `includes` → [`isIncludedIn`](/perkakas/functions#isIncludedIn).

- In Ramda `includes` also works on strings; use the native JS
  [`String.prototype.includes`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/includes)
  for strings instead.
- Ramda performs a deep equality check for the item, making `includes` useful
  for array and object items too. In Perkakas the comparison is performed via the
  JS native [`Array.prototype.includes`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/includes).
  For deep equality use the native [`Array.prototype.some`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/some)
  with Perkakas's [`isDeepEqual`](/perkakas/functions#isDeepEqual).

#### Arrays

```ts
// Ramda
includes(1, [1, 2, 3]);

// Perkakas
isIncludedIn(1, [1, 2, 3]);
```

#### Strings

```ts
const DATA = 'Hello, World!';

// Perkakas
includes('lo', DATA);

// Native
DATA.includes('lo');
```

#### Object items

```ts
const DATA = [{ name: 'Fred' }];

// Ramda
includes({ name: 'Fred' }, DATA);

// Perkakas
DATA.some(isDeepEqual({ name: 'Fred' }));
```

#### Array items

```ts
const DATA = [[42]];

// Ramda
includes([42], DATA);

// Perkakas
DATA.some(isDeepEqual([42]));
```

## mapAccum

Ramda `mapAccum` → [`mapWithFeedback`](/perkakas/functions#mapWithFeedback).

Perkakas's `mapWithFeedback` has some differences from Ramda's `mapAccum`, but
could be used to achieve the same results:

- The mapper function only returns a single value for both the accumulator and
  the value (like `reduce` does). `mapWithFeedback` would not work if you need
  these to have different values.
- Only the accumulated array is returned instead of a tuple. The final result of
  the computation would always be the last element in this list, and could be
  retrieved using [`last`](/perkakas/functions#last).

```ts
// Ramda
const result = mapAccum((a, b) => [a + b, a + b], 0, ['1', '2', '3', '4']);

// Perkakas
const temp = mapWithFeedback(['1', '2', '3', '4'], (a, b) => a + b, 0);
const result = [last(temp), temp];
```

## max

No direct Perkakas helper. Use the notes below, or native JavaScript.

_Not provided by Perkakas._

The Ramda `max` function takes exactly **2** arguments. It is easily replicated
using native JS operators.

```ts
// Ramda
max(a, b);

// Curried
const maxA = max(a);

// Native
a > b ? a : b;

const maxA = (b: number) => (a > b ? a : b);
```

## maxBy

Ramda `maxBy` → [`firstBy`](/perkakas/functions#firstBy).

The Perkakas `firstBy` returns what would be the first item in an array if it was
sorted by the order criteria (without actually sorting the array). Ramda's
`maxBy` could be rebuilt using `firstBy` by taking the mapping function in
descending order, and wrapping the 2 arguments with an array.

```ts
// Ramda
maxBy(mapperFunc, a, b);

// Perkakas
firstBy([a, b], [mapperFunc, 'desc']);
```

## not

No direct Perkakas helper. Use the notes below, or native JavaScript.

_Not provided by Perkakas._

- Use the native [logical NOT operator `!`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_NOT).
- Ramda's `not` is a function, so it can be passed around point-free. The native

#### Values

```ts
// Ramda

// Native
```

```ts

// Perkakas
```

## nth

No direct Perkakas helper. Use the notes below, or native JavaScript.

_Not provided by Perkakas._

- For index `0` use [`first`](/perkakas/functions#first).
- For index `-1` use [`last`](/perkakas/functions#last).
- For arbitrary _non-negative_ indices use the native JS `data[n]`.
- Or use [`Array.prototype.at`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/at) for any index.

```ts
// Ramda
nth(0, DATA);

// Perkakas
first(DATA);

// Ramda
nth(1, DATA);

// Native
DATA[1];
DATA.at(1);

// Ramda
nth(-1, DATA);

// Perkakas
last(DATA);

// Ramda
nth(-2, DATA);

// Native
DATA.at(-2);
```

## range

Ramda `range` → [`range`](/perkakas/functions#range).

Perkakas curries functions by stripping the first parameter. This means that
unlike in Ramda, a curried call to `range` would result in a function that has
a pre-set `end` value, and not a pre-set `start` value; curried calls need their
`start` and `end` parameters swapped!

#### Simple

```ts
// Ramda
R.range(10, 20);
R.range(start, end);

// Perkakas
range(10, 20);
range(start, end);
```

#### Curried

```ts
// Ramda
R.range(10)(20);
R.range(start)(end);

// Perkakas
range(20)(10);
range(end)(start);
```

Perkakas's `sortBy` also covers the use-case of `sortWith` using a simpler syntax
to describe complex sorting logic; the function takes a variadic list of
arguments instead of an array, and the sorting direction (ascending/descending)
is determined by an optional tuple syntax for the operator.

```ts
const DATA = [
  {
    name: 'clara',
    age: 40,
  },
  {
    name: 'bob',
    age: 30,
  },
  {
    name: 'alice',
    age: 40,
  },
];

// Ramda
sortWith([descend(prop('age')), ascend(prop('name'))])(DATA);

// Perkakas
sortBy(DATA, [prop('age'), 'desc'], prop('name'));

// Or in a pipe
pipe(DATA, sortBy([prop('age'), 'desc'], prop('name')));
```

## T

Ramda `T` → [`constant`](/perkakas/functions#constant).

Use `constant` with the constant `true`. Notice that in Ramda you use `T` itself
as the function, but in Perkakas `constant` is a factory that _creates_ the
replacement function.

```ts
// Ramda
T;

// Perkakas
constant(true);
```

## tail

Ramda `tail` → [`drop`](/perkakas/functions#drop).

- Equivalent to `drop` with an argument of `1`.
- On strings use [`sliceString`](/perkakas/functions#sliceString) instead.

#### Arrays

```ts
// Ramda
tail([1, 2, 3]);

// Perkakas
drop([1, 2, 3], 1);
```

#### Strings

```ts
// Ramda
tail('abc');

// Perkakas
sliceString('abc', 1);
```
