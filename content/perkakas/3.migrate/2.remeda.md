Perkakas tracks Remeda's function set. A typical move is an install swap, an import rename, and `purry` → [`curry`](/perkakas/functions#curry).

## Install

Replace `remeda` with `@vinicunca/perkakas`.

::code-group{sync="pm"}

```bash [pnpm]
pnpm remove remeda
pnpm add @vinicunca/perkakas
```

```bash [npm]
npm uninstall remeda
npm install @vinicunca/perkakas
```

```bash [yarn]
yarn remove remeda
yarn add @vinicunca/perkakas
```

```bash [bun]
bun remove remeda
bun add @vinicunca/perkakas
```

::

## Imports

```ts
// Perkakas
import { curry, filter, map, pipe } from '@vinicunca/perkakas';
// Remeda
import { filter, map, pipe, purry } from 'remeda';
```

You can keep importing individual helpers. There is no default export.

## `purry` is `curry`

[`curry`](/perkakas/functions#curry) is Remeda's `purry`: it builds the data-first / data-last pair most Perkakas functions use. It is not type-safe on its own — wrap it with your own overloads, the way the library does.

```ts
import { curry } from '@vinicunca/perkakas';

function findIndex<T>(array: Array<T>, fn: (item: T) => boolean): number;
function findIndex<T>(fn: (item: T) => boolean): (array: Array<T>) => number;
function findIndex(...args: ReadonlyArray<unknown>): unknown {
  return curry(findIndexImplementation, args);
}
```

## Perkakas-only exports

These are not in Remeda. One-line descriptions below match the JSDoc (or the source, when JSDoc is missing).

| Export | What it does |
| --- | --- |
| [`curry`](/perkakas/functions#curry) | Remeda's `purry`: build data-first and data-last signatures. |
| [`humanReadableFileSize`](/perkakas/functions#humanReadableFileSize) | Format a byte count as a human-readable size (`1.0 kB`, `2.0 MiB`). |
| [`sleep`](/perkakas/functions#sleep) | Return a promise that resolves after a given number of milliseconds. |
| [`slugify`](/perkakas/functions#slugify) | Turn a string into a URL/DOM-safe slug. |
| [`KEY_CODES`](/perkakas/functions#KEY_CODES) | Keyboard `event.code` name constants (`ENTER`, `ESC`, …). |
| [`isBrowser`](/perkakas/functions#isBrowser) | `true` when `window` is defined. |
| [`DeepPartial`](/perkakas/functions#DeepPartial) | Recursive `Partial<T>`, exported from `type.helpers`. |

`KEY_CODES`, `isBrowser`, and `DeepPartial` have no `@category` tag in source, so they land under **Other** on the [Functions](/perkakas/functions) page.
