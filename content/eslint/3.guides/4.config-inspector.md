[@eslint/config-inspector](https://github.com/eslint/config-inspector) is ESLint's official visualizer for flat configs. It is **not** a Vinicunca- or antfu-specific tool.

## Run it

From a project that already has `eslint.config.js` (or `.mjs` / `.ts`):

```bash
pnpm dlx @eslint/config-inspector
```

Or add a script that uses the local ESLint config:

```json [package.json]
{
  "scripts": {
    "lint:inspect": "eslint --inspect-config"
  }
}
```

`eslint --inspect-config` opens the same inspector (ESLint 9+).

## What to look for

- Config items named `vinicunca/javascript/rules`, `vinicunca/stylistic/rules`, `vinicunca/vue/rules`, and so on.
- The `files` / `ignores` globs for each item.
- Plugins after renaming (`ts`, `style`, `react`, `yaml`, …).
- Your extra configs at the **end** of the list — they should win on overlapping rules.

Use this when an override "doesn't apply": the glob or the config name is usually wrong. Copy the name into `.override('vinicunca/...', { rules: { ... } })`.
