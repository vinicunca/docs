## From Prettier

This config formats JavaScript, TypeScript, Vue, JSON, YAML, TOML and Markdown code blocks with ESLint. Use [formatters](/eslint/configuration/formatters) for CSS, HTML, XML, GraphQL and Astro instead of a separate Prettier CLI.

::steps{level="3"}

### Install ESLint and the config

::code-group{sync="pm"}

```bash [pnpm]
pnpm add -D eslint @vinicunca/eslint-config
```

```bash [npm]
npm install -D eslint @vinicunca/eslint-config
```

```bash [yarn]
yarn add -D eslint @vinicunca/eslint-config
```

```bash [bun]
bun add -d eslint @vinicunca/eslint-config
```

::

### Add `eslint.config.js`

```js [eslint.config.js]
import { vinicuncaESLint } from '@vinicunca/eslint-config';

export default vinicuncaESLint({
  formatters: {
    css: true,
    html: true,
  },
});
```

Drop `formatters` if you only care about JS/TS/Vue. Enable more languages as needed.

### Point the editor at ESLint

Use the [VS Code settings](/eslint/getting-started#vs-code): `"prettier.enable": false`, `"editor.formatOnSave": false`, and `source.fixAll.eslint` on save.

### Remove Prettier from JS/TS

Uninstall `prettier`, `eslint-config-prettier` and `eslint-plugin-prettier` if they were only formatting application code. Keep Prettier **only** if a `formatters.*` option needs a plugin (for example `@prettier/plugin-xml`).

Delete `.prettierrc*` and Prettier entries in `package.json`. ESLint Stylistic does not read Prettier config files.

### Fix the repo once

```bash
pnpm eslint --fix
```

Review the diff: semicolons are **on**, arrow parameters are always parenthesized, and imports are sorted.

::

## From antfu/eslint-config

1. Replace the package with `@vinicunca/eslint-config`.
2. Change `import antfu from '@antfu/eslint-config'` to `import { vinicuncaESLint } from '@vinicunca/eslint-config'`.
3. Call `vinicuncaESLint(...)` instead of `antfu(...)`.
4. Replace composer names `antfu/` with `vinicunca/`.
5. Expect style churn: semicolons, `1tbs` braces in JS/TS, always-parens arrows. `lessOpinionated` will not relax rules.
6. There is no CLI wizard and no `angular` option.

See [Differences from antfu/eslint-config](/eslint/guides/differences-from-antfu).

## From eslint-config-airbnb, Standard, or `extends`

Flat config does not use `extends` from `.eslintrc`. Delete `.eslintrc*` and `.eslintignore` (use `ignores` in the factory). Start from `vinicuncaESLint()` and re-apply only the rules you still need as extra configs.

```js [eslint.config.js]
import { vinicuncaESLint } from '@vinicunca/eslint-config';

export default vinicuncaESLint(
  {
    ignores: ['legacy/**'],
  },
  {
    files: ['legacy/**/*.js'],
    rules: {
      'no-var': 'off',
    },
  },
);
```

To reuse an old eslintrc snippet, wrap it with [`@eslint/eslintrc` FlatCompat](https://www.npmjs.com/package/@eslint/eslintrc) and pass the result as a later argument — prefer rewriting to flat configs when you can.

## Git hooks

Keep [lint-staged](/eslint/getting-started#git-hooks) running `eslint --fix` on `*`. You no longer need `prettier --write` in that hook for files ESLint already formats.
