All options go in the first argument of `vinicuncaESLint()`. Options typed `boolean | object` turn the integration on when you pass an object.

```js [eslint.config.js]
import { vinicuncaESLint } from '@vinicunca/eslint-config';

export default vinicuncaESLint({
  type: 'lib',
  stylistic: { indent: 2, quotes: 'single' },
  typescript: { tsconfigPath: 'tsconfig.json' },
});
```

## General

::field-group

  ::field{name="type" type="'app' | 'lib'"}
  Defaults to `'app'`. `'lib'` also enables `ts/explicit-function-return-type` (expressions, higher-order functions and IIFEs are allowed) for published libraries.
  ::

  ::field{name="ignores" type="string[] | ((originals: string[]) => string[])"}
  Defaults to `[]`. Global ignore globs. An array **extends** the built-in list (`node_modules`, `dist`, lockfiles, `coverage`, `.nuxt`, `.next`, `.output`, `CHANGELOG*.md`, `*.min.*`, `__snapshots__`, `.claude`, `.agents` and more). A function receives the built-in list and returns the final one. When TypeScript support is off, `*.ts` and `*.tsx` files are ignored too.
  ::

  ::field{name="gitignore" type="boolean | FlatGitignoreOptions"}
  Defaults to `true`. Adds the patterns from `.gitignore` to the ignores, without failing when the file is missing. Pass an object to configure [eslint-config-flat-gitignore](https://github.com/antfu/eslint-config-flat-gitignore) (for example `files` or `strict`).
  ::

  ::field{name="isInEditor" type="boolean"}
  Defaults to auto-detection (VS Code, JetBrains IDEs, Vim, Neovim, Zed; never in CI, git hooks or lint-staged). When `true`, `prefer-const`, `unused-imports/no-unused-imports` and `test/no-only-tests` become non-fixable warnings. See [Editor-specific behavior](/eslint/getting-started#editor-specific-behavior).
  ::

  ::field{name="autoRenamePlugins" type="boolean"}
  Defaults to `true`. Renames plugin prefixes (for example `@typescript-eslint` to `ts`) in every config, including yours. See [Plugin renaming](/eslint/configuration/rules-overrides#plugin-renaming).
  ::

  ::field{name="componentExts" type="string[]"}
  Defaults to `[]`. Extra file extensions treated as components: they are parsed by the TypeScript parser and linted inside Markdown code blocks. `vue` is added automatically when Vue support is on.
  ::

  ::field{name="lessOpinionated" type="boolean"}
  Defaults to `false`. Accepted for compatibility with antfu/eslint-config but currently has **no effect**: `curly`, `antfu/top-level-function` and the other stylistic rules stay on.
  ::

::

The first argument also accepts the flat config properties `name`, `languageOptions`, `linterOptions`, `processor`, `plugins`, `rules` and `settings` (but not `files`). See [Options](/eslint/configuration#options).

## JavaScript and core rules

::field-group

  ::field{name="javascript" type="{ overrides?: Rules }"}
  Core JavaScript rules. Always enabled; use `overrides` to change them.
  ::

  ::field{name="node" type="boolean"}
  Defaults to `true`. Node.js rules from `eslint-plugin-n` (renamed `node/*`).
  ::

  ::field{name="jsdoc" type="boolean"}
  Defaults to `true`. JSDoc rules (as warnings) from `eslint-plugin-jsdoc`.
  ::

  ::field{name="imports" type="boolean | { overrides?: Rules }"}
  Defaults to `true`. Import hygiene rules from `eslint-plugin-import-lite` (renamed `import/*`) and `eslint-plugin-antfu`.
  ::

  ::field{name="perfectionist" type="boolean | { overrides?: Rules }"}
  Defaults to `true`. Sorts imports, exports, named imports and named exports with `eslint-plugin-perfectionist`.
  ::

  ::field{name="unicorn" type="boolean | { allRecommended?: boolean }"}
  Defaults to `true`. A curated set of `eslint-plugin-unicorn` rules. `allRecommended: true` (default `false`) uses the plugin's full recommended set instead. The `overrides` key is accepted by the type but currently ignored; override unicorn rules in an extra config.
  ::

  ::field{name="e18e" type="boolean | OptionsE18e"}
  Defaults to `true`. Ecosystem performance rules from [@e18e/eslint-plugin](https://github.com/e18e/eslint-plugin). See [e18e options](#e18e).
  ::

  ::field{name="regexp" type="boolean | { level?: 'error' | 'warn', overrides?: Rules }"}
  Defaults to `true`. The recommended rules of `eslint-plugin-regexp`. `level: 'warn'` downgrades every error to a warning.
  ::

  ::field{name="test" type="boolean | { overrides?: Rules }"}
  Defaults to `true`. Rules for `*.test.*`, `*.spec.*`, `*.bench.*`, `*.benchmark.*` and `__tests__/**` files, from `@vitest/eslint-plugin` and `eslint-plugin-no-only-tests` (both under `test/*`).
  ::

::

### e18e

::field-group

  ::field{name="modernization" type="boolean"}
  Defaults to `true`. Rules that prefer modern built-in APIs.
  ::

  ::field{name="moduleReplacements" type="boolean"}
  Defaults to `false` in practice. The type docs say `type === 'lib' && isInEditor`, but the factory doesn't forward `type` to this integration, so set it explicitly to enable it.
  ::

  ::field{name="performanceImprovements" type="boolean"}
  Defaults to `true`. Rules that flag slow patterns.
  ::

  ::field{name="overrides" type="Rules"}
  Rule overrides for `e18e/*`. `e18e/prefer-static-regex` and the array-copy rules (`prefer-array-at`, `prefer-array-from-map`, `prefer-array-to-reversed`, `prefer-array-to-sorted`, `prefer-array-to-spliced`, `prefer-spread-syntax`) are off by default.
  ::

::

## Stylistic

::field-group

  ::field{name="stylistic" type="boolean | StylisticOptions"}
  Defaults to `true`. Formatting rules from [ESLint Stylistic](https://eslint.style/) (renamed `style/*`). Pass `false` if you format with another tool, or an object with the keys below.
  ::

::

### Stylistic options

::field-group

  ::field{name="indent" type="number | 'tab'"}
  Defaults to `2`. Also used for JSON, YAML, TOML, Vue templates, Svelte and the Prettier/dprint formatters.
  ::

  ::field{name="quotes" type="'single' | 'double' | 'backtick'"}
  Defaults to `'single'`.
  ::

  ::field{name="semi" type="boolean"}
  Defaults to `true`. Set `false` to forbid semicolons.
  ::

  ::field{name="jsx" type="boolean"}
  Defaults to the value of the [`jsx`](#languages) option. Enables JSX stylistic rules.
  ::

  ::field{name="braceStyle" type="'1tbs' | 'stroustrup' | 'allman'"}
  Defaults to `'stroustrup'`, but JavaScript and TypeScript **always use `1tbs`** (`} else {`) because the config sets `style/brace-style` without options. The value only reaches `vue/brace-style` in Vue templates. To change the brace style, override `style/brace-style`.
  ::

  ::field{name="experimental" type="boolean"}
  Defaults to `false`. Enables ESLint Stylistic's experimental rules and drops `antfu/consistent-list-newline`.
  ::

  ::field{name="overrides" type="Rules"}
  Rule overrides merged into `vinicunca/stylistic/rules`.
  ::

::

## TypeScript

::field-group

  ::field{name="typescript" type="boolean | OptionsTypescript"}
  Defaults to `true` when `typescript` or `@typescript/native-preview` is installed. Pass an object with the keys below to configure it. See [TypeScript](/eslint/configuration/typescript).
  ::

::

### TypeScript options

::field-group

  ::field{name="tsconfigPath" type="string"}
  Path to your `tsconfig.json`. Setting it enables [type-aware rules](/eslint/configuration/typescript#type-aware-rules).
  ::

  ::field{name="overrides" type="Rules"}
  Overrides for `vinicunca/typescript/rules`.
  ::

  ::field{name="overridesTypeAware" type="Rules"}
  Overrides for `vinicunca/typescript/rules-type-aware`. Only used when `tsconfigPath` is set.
  ::

  ::field{name="filesTypeAware" type="string[]"}
  Defaults to `['**/*.?([cm])ts', '**/*.?([cm])tsx']`. Files that get type-aware parsing and rules.
  ::

  ::field{name="ignoresTypeAware" type="string[]"}
  Defaults to `['**/*.md/**', '**/*.astro/*.ts']`. Files excluded from type-aware parsing and rules.
  ::

  ::field{name="parserOptions" type="Partial<ParserOptions>"}
  Extra options for `@typescript-eslint/parser`, merged last.
  ::

  ::field{name="erasableOnly" type="boolean"}
  Defaults to `false`. Forbids TypeScript syntax that can't be erased (enums, namespaces, parameter properties, import/export aliases), for Node.js type stripping.
  ::

::

## Languages

::field-group

  ::field{name="jsx" type="boolean | { a11y?: boolean | { overrides?: Rules } }"}
  Defaults to `true`. Enables JSX parsing for `*.jsx`/`*.tsx` and JSX stylistic rules. `a11y` (default `false`) adds the recommended rules of `eslint-plugin-jsx-a11y`, which you must install.
  ::

  ::field{name="jsonc" type="boolean | { overrides?: Rules }"}
  Defaults to `true`. Lints `*.json`, `*.json5` and `*.jsonc`, and sorts the keys of `package.json`, `tsconfig.json`, `tsconfig.*.json` and `jsconfig.json`.
  ::

  ::field{name="yaml" type="boolean | { overrides?: Rules }"}
  Defaults to `true`. Lints `*.yaml` and `*.yml` with `eslint-plugin-yml` (renamed `yaml/*`).
  ::

  ::field{name="toml" type="boolean | { overrides?: Rules }"}
  Defaults to `true`. Lints `*.toml` with `eslint-plugin-toml`.
  ::

  ::field{name="markdown" type="boolean | OptionsMarkdown"}
  Defaults to `true`. Lints Markdown files with `@eslint/markdown` and the code blocks inside them. See [Markdown options](#markdown-options).
  ::

::

### Markdown options

::field-group

  ::field{name="gfm" type="boolean"}
  Defaults to `true`. Parses Markdown as GitHub Flavored Markdown. `false` uses CommonMark.
  ::

  ::field{name="overrides" type="Rules"}
  Overrides for the **code blocks** inside Markdown files (`vinicunca/markdown/disables`).
  ::

  ::field{name="overridesMarkdown" type="Rules"}
  Overrides for the Markdown document itself (`vinicunca/markdown/rules`).
  ::

::

## Frameworks

::field-group

  ::field{name="vue" type="boolean | OptionsVue"}
  Defaults to `true` when `vue`, `nuxt`, `vitepress` or `@slidev/cli` is installed. See [Vue options](#vue-options).
  ::

  ::field{name="react" type="boolean | { overrides?: Rules }"}
  Defaults to `false`. Requires `@eslint-react/eslint-plugin` and `eslint-plugin-react-refresh`.
  ::

  ::field{name="nextjs" type="boolean | { overrides?: Rules }"}
  Defaults to `false`. Requires `@next/eslint-plugin-next`.
  ::

  ::field{name="svelte" type="boolean | { overrides?: Rules }"}
  Defaults to `false`. Requires `eslint-plugin-svelte` and `svelte-eslint-parser`.
  ::

  ::field{name="solid" type="boolean | { overrides?: Rules }"}
  Defaults to `false`. Requires `eslint-plugin-solid`.
  ::

  ::field{name="astro" type="boolean | { overrides?: Rules }"}
  Defaults to `false`. Requires `eslint-plugin-astro` and `astro-eslint-parser`.
  ::

  ::field{name="unocss" type="boolean | OptionsUnoCSS"}
  Defaults to `false`. `@unocss/eslint-plugin` ships with the config. See [UnoCSS options](#unocss-options).
  ::

::

See [Frameworks](/eslint/configuration/frameworks) for examples.

### Vue options

::field-group

  ::field{name="a11y" type="boolean"}
  Defaults to `false`. Adds accessibility rules from `eslint-plugin-vuejs-accessibility` (renamed `vue-a11y/*`), which you must install.
  ::

  ::field{name="sfcBlocks" type="boolean | VueBlocksOptions"}
  Defaults to `true`. Creates virtual files for SFC blocks with [eslint-processor-vue-blocks](https://github.com/antfu/eslint-processor-vue-blocks) so `<style>` blocks can be linted and formatted. `false` uses only the Vue processor.
  ::

  ::field{name="vueVersion" type="2 | 3"}
  Defaults to `3`. Currently **has no effect**: the Vue 3 rule sets are always used.
  ::

  ::field{name="overrides" type="Rules"}
  Overrides for `vinicunca/vue/rules`.
  ::

::

### UnoCSS options

::field-group

  ::field{name="attributify" type="boolean"}
  Defaults to `false` (the type docs say `true`, but the config uses `false`). Enables `unocss/order-attributify`.
  ::

  ::field{name="strict" type="boolean"}
  Defaults to `false`. Reports blocklisted classes with `unocss/blocklist`.
  ::

  ::field{name="configPath" type="string"}
  Path to `uno.config.ts`, useful in monorepos.
  ::

::

The `overrides` key is accepted for `unocss` but currently ignored; override `unocss/*` rules in an extra config.

## Optional configs

::field-group

  ::field{name="formatters" type="boolean | OptionsFormatters"}
  Defaults to `false`. Formats CSS, HTML, XML, SVG, Markdown, GraphQL and Astro files with Prettier or dprint. See [Formatters](/eslint/configuration/formatters).
  ::

  ::field{name="antislop" type="boolean | OptionsAntislop"}
  Defaults to `false`. **Experimental.** Rules against low-value code patterns. Requires `eslint-plugin-slop` and `eslint-plugin-sonarjs`. See [Antislop options](#antislop-options).
  ::

  ::field{name="pnpm" type="boolean | OptionsPnpm"}
  Defaults to `true` when a `pnpm-workspace.yaml` is found in the current directory or a parent. **Experimental.** See [pnpm options](#pnpm-options).
  ::

::

### Formatters options

::field-group

  ::field{name="css" type="boolean | 'prettier'"}
  Formats `*.css`, `*.pcss`, `*.postcss`, `*.scss` and `*.less` (and Vue `<style>` blocks) with Prettier.
  ::

  ::field{name="html" type="boolean | 'prettier'"}
  Formats `*.html` and `*.htm` with Prettier.
  ::

  ::field{name="xml" type="boolean | 'prettier'"}
  Formats `*.xml` with Prettier. Requires `@prettier/plugin-xml`.
  ::

  ::field{name="svg" type="boolean | 'prettier'"}
  Formats `*.svg` with Prettier. Requires `@prettier/plugin-xml`.
  ::

  ::field{name="markdown" type="boolean | 'prettier' | 'dprint'"}
  Formats `*.md`. `true` means Prettier.
  ::

  ::field{name="graphql" type="boolean | 'prettier'"}
  Formats `*.graphql` and `*.gql` with Prettier.
  ::

  ::field{name="astro" type="boolean | 'prettier'"}
  Formats `*.astro` with Prettier. Requires `prettier-plugin-astro`.
  ::

  ::field{name="slidev" type="boolean | { files?: string[] }"}
  Formats Slidev decks (`**/slides.md` by default) with `prettier-plugin-slidev`. Only works when `markdown` uses Prettier.
  ::

  ::field{name="prettierOptions" type="PrettierOptions"}
  Prettier options merged over the defaults derived from your stylistic options.
  ::

  ::field{name="dprintOptions" type="object"}
  dprint options for Markdown, merged over the defaults. Typed as `boolean` in v5.7.1, so TypeScript users need a cast.
  ::

::

### Antislop options

::field-group

  ::field{name="slop" type="boolean | { cwd?: string, inspection?: 'full' | 'uncommitted' | 'recent-changes' | object }"}
  Defaults to `true`. Enables `eslint-plugin-slop` rules. An object is forwarded to the plugin as `settings.slop`.
  ::

  ::field{name="sonarjs" type="boolean"}
  Defaults to `true`. Enables a curated subset of `eslint-plugin-sonarjs` rules.
  ::

  ::field{name="cognitiveComplexity" type="number | false"}
  Defaults to `15`. Threshold for `sonarjs/cognitive-complexity`; `false` turns the rule off.
  ::

  ::field{name="overrides" type="Rules"}
  Overrides for `vinicunca/antislop/rules/javascript`.
  ::

::

### pnpm options

::field-group

  ::field{name="catalogs" type="boolean"}
  Defaults to `true` when `pnpm-workspace.yaml` mentions `catalog:` or `catalogs:`. Enforces [catalog](https://pnpm.io/catalogs) usage in `package.json` with `pnpm/json-enforce-catalog`.
  ::

  ::field{name="json" type="boolean"}
  Defaults to `true` unless `jsonc` is `false`. Lints `package.json` files.
  ::

  ::field{name="yaml" type="boolean"}
  Defaults to `true` unless `yaml` is `false`. Lints `pnpm-workspace.yaml`.
  ::

  ::field{name="sort" type="boolean"}
  Defaults to `true` (the type docs say `false`). Sorts the keys of `pnpm-workspace.yaml`.
  ::

::

See [Optional configs](/eslint/configuration/optional-configs) for what each one checks.
