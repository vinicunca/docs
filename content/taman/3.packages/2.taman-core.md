Version **0.1.0**. ESM only. Peer: `vue` ^3.5; optional peer `vue-router` ^5 (for `./typings`).

```bash
pnpm add @vinicunca/taman-core vue
```

There is **no** root export. Import a subpath.

With `skipLibCheck: false`, you also need `@types/web-bluetooth`, `vue-component-type-helpers`, and `ESNext` in `lib` (for `Temporal`) because of `@vueuse/core` and `akar` — not because of taman-core itself.

## `@vinicunca/taman-core/color`

```ts
import { colordx } from '@vinicunca/taman-core/color';
import { generatorColorVariables } from '@vinicunca/taman-core/color';
import { convertToHsl, convertToHslCssVar, convertToRgb, isValidColor } from '@vinicunca/taman-core/color';

generatorColorVariables([{ name: 'primary', color: '#3b82f6' }])
// → { '--taman-color-primary-500': 'oklch(...)', '--taman-color-primary': '...', ... }
```

`colordx` is `@colordx/core` with the mix plugin. `convertToRgb` strips `deg|grad|rad|turn` before TinyColor parse.

## `@vinicunca/taman-core/cache`

`StorageManager` + drivers. Prefix isolation and TTL live on the manager; drivers are pure KV.

```ts
import {
  StorageManager,
  LocalStorageDriver,
  IndexedDBDriver,
  MemoryStorageDriver,
} from '@vinicunca/taman-core/cache';

const cache = new StorageManager({ prefix: 'myapp' });
// StorageManager({ driver?: IStorageDriver, prefix?: string })
// Default driver: LocalStorageDriver in the browser, MemoryStorageDriver on Node / if localStorage throws.

await cache.setItem(key, value, ttlMs?)
await cache.getItem<T>(key, defaultValue?)   // expired → default, item removed
await cache.removeItem(key)
await cache.clear()            // keys with this prefix only
await cache.clearExpiredItems()
await cache.keys()             // prefix stripped
cache.getFullKey(key)
```

Empty `prefix` + `LocalStorageDriver` logs a warning: `clear()` / `keys()` would touch **all** of localStorage.

The in-repo `src/cache/README.md` is a leftover bilingual/garbled draft. Trust this page and the TypeScript source.

## `@vinicunca/taman-core/typings`

Menu, tab, layout, and `RouteMeta` augmentation for `vue-router`. Importing this module (or listing it in `compilerOptions.types`) adds Taman fields to `RouteMeta`. See [Permissions](/taman/guides/permissions) for `authority` / `auth` / `TamanRoleRegistry`.

## `@vinicunca/taman-core/preferences`

See [Preferences](/taman/guides/preferences-layouts-theming).


`initPreferences` is a no-op if already initialized. Merge order: overrides over `defaultPreferences`; cache fills **unset** fields only.
