Version **0.1.1**. ESM, built for Vite. Peers: `vue` ^3.5, `pohon-ui` ^2.0.0-rc7.9, `@internationalized/date` and `@internationalized/number` ^3.

The package ships **no CSS**. Styling is your (or the template's) job.

## Setup

```ts
// vite.config.ts
vitePohon({ scanPackages: ['@vinicunca/taman-ui'] })
optimizeDeps: { exclude: ['pohon-ui', '@vinicunca/taman-ui'] }
resolve: { dedupe: ['pohon-ui', 'vue'] }
```

```ts
// uno.config.ts
import { TAMAN_UI_CONTENT } from '@vinicunca/taman-ui/unocss';

content: {
  pipeline: {
    include: [/\.(vue|svelte|[jt]sx|vine.ts|mdx?|astro|elm|php|phtml|marko|html)($|\?)/, TAMAN_UI_CONTENT],
  },
}
```

`TAMAN_UI_CONTENT` is `/@vinicunca[\\/]taman-ui[\\/]dist[\\/].*\.mjs$/`.

`theme.unstyled: true` + your `ui` config = custom design (the Taman template). Leave Pohon styled for the default look.

`skipLibCheck: false` is **not** supported: pohon-ui's own declarations do not type-check in strict mode.
