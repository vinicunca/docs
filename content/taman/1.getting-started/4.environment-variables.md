`create-taman` copies each `.env*.example` to a sibling `.env`. Review those files before deploying. Nitro maps `NITRO_*` names onto `runtimeConfig` (so `NITRO_DATABASE_URL` becomes `runtimeConfig.databaseUrl`).

## API (`apps/api/.env`)

Read via `useRuntimeConfig()` in `apps/api/nitro.config.ts` and `server/auth/better-auth.instance.ts`.

::field-group

:::field{name="NITRO_DATABASE_URL" type="string" required}
Postgres URL. Default matches Docker Compose: `postgresql://postgres:postgres@localhost:5437/taman_db`. Also accepted as `DATABASE_URL` by the seed scripts.
:::

:::field{name="NITRO_TRUSTED_ORIGINS" type="string" required}
Comma-separated browser origins allowed to call the API. Default: `http://localhost:5556,http://localhost:5560` (the dev server and the Playwright e2e server). Empty after trim means **no** origins (CORS allow-list is empty); there is no localhost fallback.
:::

:::field{name="NITRO_BASE_URL" type="string" required}
Public URL of this API. better-auth `baseURL`. Default: `http://localhost:8788`.
:::

:::field{name="NITRO_APP_URL" type="string" required}
Public URL of the web app (invitation links). Default: `http://localhost:5556`.
:::

:::field{name="NITRO_BETTER_AUTH_SECRET" type="string" required}
better-auth secret. At least 32 random characters (`openssl rand -base64 32`). The example value is a placeholder.
:::

:::field{name="NITRO_GOOGLE_CLIENT_ID" type="string"}
Google OAuth client ID. Empty disables a working Google login until you set both Google vars.
:::

:::field{name="NITRO_GOOGLE_CLIENT_SECRET" type="string"}
Google OAuth client secret.
:::

:::field{name="NITRO_EMAIL_FROM" type="string" required}
From address for transactional email. Default: `no-reply@example.com`.
:::

:::field{name="NITRO_EMAIL_FROM_NAME" type="string"}
From display name. Default: `Taman` (rewritten to the project name on generate).
:::

::

Cloudflare bindings (`TODO_PUBLISHER`, `EMAIL_QUEUE`, `EMAIL`) come from `nitro.config.ts` wrangler config, not `.env`.

## Database package (`packages/server/db-pg/.env`)

Used by drizzle-kit (`studio`, `generate`, `migrate`).

::field-group

:::field{name="DATABASE_URL" type="string" required}
Same Postgres URL as the API. Default: `postgresql://postgres:postgres@localhost:5437/taman_db`. `drizzle.config.ts` throws if this is unset. UAT/prod nx configurations read `.env.uat` / `.env.prod` instead.
:::

::

## Web — shared (`apps/web/.env.example`)

Always loaded. Used for storage keys and the document title.

::field-group

:::field{name="VITE_APP_TITLE" type="string" required}
Browser tab title and PWA manifest name. Default: `Taman`.
:::

:::field{name="VITE_APP_NAMESPACE" type="string" required}
Prefix for preferences and store keys. Combined in `main.ts` as `${namespace}-${version}-${dev|prod}`. Default: `taman`.
:::

:::field{name="VITE_APP_STORE_SECURE_KEY" type="string" required}
Encrypts persisted Pinia state via `secure-ls`. Replace before production.
:::

::

## Web — development (`apps/web/.env.development.example`)

Loaded in `vite --mode development`.

::field-group

:::field{name="VITE_PORT" type="number"}
Dev server port. Default in this file: `5556`. vite-config's own fallback is `5173` if unset.
:::

:::field{name="VITE_BASE" type="string"}
Vite `base`. Default: `/`.
:::

:::field{name="VITE_API_URL" type="string" required}
API origin used by the oRPC and better-auth clients. Default: `http://localhost:8788`.
:::

:::field{name="VITE_NITRO_MOCK" type="boolean"}
Nitro mock flag. Default: `false`.
:::

:::field{name="VITE_DEVTOOLS" type="boolean"}
Vue DevTools plugin. Default: `true`.
:::

:::field{name="VITE_INJECT_APP_LOADING" type="boolean"}
Injects the loading screen. Default: `true`.
:::

::

## Web — production (`apps/web/.env.production.example`)

Loaded in `vite build --mode production`.

::field-group

:::field{name="VITE_BASE" type="string"}
Same as development.
:::

:::field{name="VITE_API_URL" type="string" required}
Public API URL, e.g. `https://api.example.com`.
:::

:::field{name="VITE_COMPRESS" type="string"}
Comma-separated `gzip` / `brotli`, or `none`. Default: `none`.
:::

:::field{name="VITE_PWA" type="boolean"}
Enable `vite-plugin-pwa`. Default: `false`.
:::

:::field{name="VITE_ROUTER_HISTORY" type="string"}
`hash` or `history`. Default in this file: `hash`.
:::

:::field{name="VITE_INJECT_APP_LOADING" type="boolean"}
Default: `true`.
:::

:::field{name="VITE_ARCHIVER" type="boolean"}
Zip `dist` after build. Default: `false`.
:::

::

## Runtime contracts (vite-config)

These names are emitted by `@vinicunca/vite-config` and read by Taman packages:

- `window._TAMAN_ADMIN_DEV_CONFIG_` — in production builds, `VITE_GLOB_*` values are written to `_app-config-[version]-[hash].js` so they can change without a rebuild.
- `__TAMAN_METADATA__` — author, version, build time, dependency versions.
- Loading screen dark-mode key: `localStorage["${VITE_APP_NAMESPACE}-${version}-${dev|prod}-preferences-theme"]`.

See [vite-config](/taman/packages/tooling) for the full option table.
