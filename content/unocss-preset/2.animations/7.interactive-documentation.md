## Interactive documentation

1. Copy the config below.
2. Open the [UnoCSS interactive docs](https://unocss.dev/interactive/).
3. Open settings (gear icon, top right), paste the config, and confirm.

```ts [uno.config.ts]
import { presetVinicunca } from '@vinicunca/unocss-preset';
import { defineConfig } from 'unocss';

export default defineConfig({
  presets: [
    presetVinicunca({
      animation: {
        fillMode: 'both'
      }
    })
  ]
});
```

`fillMode` belongs under `animation`. It is not a top-level `presetVinicunca` option.
