---
title: Animations
description: Enter and exit animations with fade, zoom, spin, and slide, inspired by tailwindcss-animate.
---

The animation preset is enabled by default. Pair `animate-in` or `animate-out` with fade, zoom, spin, and slide utilities. They compose: the example below fades, zooms, and slides in together.

```html
<div class="animate-in fade-in-50 zoom-in-80 slide-in-from-top-5">
  Hello there
</div>
```

::warning
Do not use the `[]` arbitrary-value syntax with these utilities. UnoCSS would copy the brackets' contents as-is, so `spin-in-[30]` emits `--vin-enter-rotate: 30` (no unit) and invalidates `transform`. Write `spin-in-30` or `spin-in-30deg` instead.
::

CSS variables use the `--vin-` prefix (`--vin-enter-opacity`, `--vin-exit-scale`, …). Keyframe names are `vin-in` and `vin-out`.

## Enter animations

Use `animate-in` with [`fade-in`](/unocss-preset/animations/fade#fade-in), [`zoom-in`](/unocss-preset/animations/zoom#zoom-in), [`spin-in`](/unocss-preset/animations/spin#spin-in), and [`slide-in`](/unocss-preset/animations/slide#slide-in).

```html
<button class="animate-in fade-in">Button A</button>
<button class="animate-in spin-in">Button B</button>
<button class="animate-in zoom-in">Button C</button>
<button class="animate-in slide-in-top">Button D</button>
```

## Exit animations

Use `animate-out` with [`fade-out`](/unocss-preset/animations/fade#fade-out), [`zoom-out`](/unocss-preset/animations/zoom#zoom-out), [`spin-out`](/unocss-preset/animations/spin#spin-out), and [`slide-out`](/unocss-preset/animations/slide#slide-out).

```html
<button class="animate-out fade-out">Button A</button>
<button class="animate-out spin-out">Button B</button>
<button class="animate-out zoom-out">Button C</button>
<button class="animate-out slide-out-bottom">Button D</button>
```

## Options

Pass an object to `animation`. All fields are optional. Time values use `unit` (default `'ms'`).

```ts [uno.config.ts]
presetVinicunca({
  animation: {
    unit: 'ms',
    duration: 200,
    fillMode: 'both'
  }
})
```

::field-group

  ::field{name="unit" type="'ms' | 's'"}
  Defaults to `'ms'`.
  ::

  ::field{name="duration" type="number"}
  When omitted, `animate-in` / `animate-out` set `animation-duration: 150ms` (hardcoded, not `theme.duration.DEFAULT`). When set, the value is `${duration}${unit}`.
  ::

  ::field{name="delay" type="number"}
  Default `animation-delay`.
  ::

  ::field{name="direction" type="'normal' | 'reverse' | 'alternate' | 'alternate-reverse'"}
  Default `animation-direction`.
  ::

  ::field{name="fillMode" type="'none' | 'forwards' | 'backwards' | 'both'"}
  Default `animation-fill-mode`. `both` is usually what you want for enter/exit.
  ::

  ::field{name="iterationCount" type="number | 'infinite'"}
  Default `animation-iteration-count`.
  ::

  ::field{name="playState" type="'running' | 'paused'"}
  Default `animation-play-state`.
  ::

  ::field{name="timingFunction" type="'linear' | 'ease' | 'ease-in' | 'ease-out' | 'ease-in-out' | string"}
  Default `animation-timing-function`.
  ::

::

Per-element timing still comes from [Wind4 animation property utilities](/unocss-preset/animations/animation-properties) such as `animate-duration-300`.

## From tailwindcss-animate

The animation classes stay familiar. Property modifiers use Wind4 names.

### `animation-delay`

| tailwindcss-animate | this preset |
| --- | --- |
| `delay-<number>` | `animate-delay-<number>` |

```html
<button class="animate-in fade-in animate-delay-150">Button A</button>
<button class="animate-in fade-in animate-delay-300">Button B</button>
<button class="animate-in fade-in animate-delay-700">Button C</button>
```

### `animation-direction`

| tailwindcss-animate | this preset |
| --- | --- |
| `direction-<keyword>` | `animate-<keyword>` or `animate-direction-<keyword>` |

```html
<button class="animate-in fade-in animate-normal">Button A</button>
<button class="animate-in fade-in animate-reverse">Button B</button>
<button class="animate-in fade-in animate-alternate">Button C</button>
<button class="animate-in fade-in animate-alternate-reverse">Button D</button>
<button class="animate-in fade-in animate-direction-normal">Button E</button>
```

### `animation-duration`

| tailwindcss-animate | this preset |
| --- | --- |
| `duration-<number>` | `animate-duration-<number>` |

```html
<button class="animate-in fade-in animate-duration-150">Button A</button>
<button class="animate-in fade-in animate-duration-300">Button B</button>
<button class="animate-in fade-in animate-duration-700">Button C</button>
```

::tip
If you do not set `animation.duration` and you do not add `animate-duration-*`, `animate-in` / `animate-out` use **`150ms`**, hardcoded in the shortcut — not `theme.duration.DEFAULT`.
::

### `animation-fill-mode`

| tailwindcss-animate | this preset |
| --- | --- |
| `fill-mode-<keyword>` | `animate-<keyword>`, `animate-fill-<keyword>`, `animate-mode-<keyword>`, or `animate-fill-mode-<keyword>` |

```html
<button class="animate-in fade-in animate-none">Button A</button>
<button class="animate-in fade-in animate-forwards">Button B</button>
<button class="animate-in fade-in animate-backwards">Button C</button>
<button class="animate-in fade-in animate-both">Button D</button>
```

### `animation-iteration-count`

| tailwindcss-animate | this preset |
| --- | --- |
| `repeat-<number\|keyword>` | `animate-iteration-*`, `animate-count-*`, or `animate-iteration-count-*` |

```html
<button class="animate-in fade-in animate-iteration-1">Button A</button>
<button class="animate-in fade-in animate-iteration-infinite">Button B</button>
<button class="animate-in fade-in animate-count-0">Button C</button>
```

### `animation-play-state`

| tailwindcss-animate | this preset |
| --- | --- |
| `running` / `paused` | `animate-<keyword>`, `animate-play-*`, `animate-state-*`, or `animate-play-state-*` |

```html
<button class="animate-in fade-in animate-paused">Button A</button>
<button class="animate-in fade-in animate-running">Button B</button>
```

### `animation-timing-function`

| tailwindcss-animate | this preset |
| --- | --- |
| `ease-<easing>` | `animate-ease-<easing>` |

```html
<button class="animate-in fade-in animate-ease-linear">Button A</button>
<button class="animate-in fade-in animate-ease-in-out">Button B</button>
```

### Prefers reduced motion

```html
<button class="motion-reduce:animate-none">Button A</button>
<button class="motion-safe:animate-in fade-in">Button B</button>
```
