Pass a single object to `presetVinicunca()`. Nested presets and transformers accept `true` to enable, `false` to disable, or an options object.

```ts [uno.config.ts]
import { presetVinicunca } from '@vinicunca/unocss-preset'
import { defineConfig } from 'unocss'

export default defineConfig({
  presets: [
    presetVinicunca({
      icons: { scale: 1.2 },
      scrollbar: true,
      alias: true
    })
  ]
})
```

There is no `presets` option on `presetVinicunca`. Nested presets are always composed internally.

## Core

::field-group

  ::field{name="preflights" type="boolean"}
  Defaults to `true`. Injects the CSS reset on the `preflights` layer. Set `false` to skip it. Wind4's reset stays off unless you pass `wind4: true` (boolean), which uses Wind4 defaults including its reset.
  ::

  ::field{name="unColor" type="boolean | string"}
  Defaults to `false`. When `true`, a postprocessor rewrites `rgb(...)` / `rgba(...)` color values so the channels live on `--un-color` and the declaration uses `rgb(var(--un-color) / <alpha>)` (or `rgba(var(--un-color) , <alpha>)`). Pass a string to use that CSS variable name instead.
  ::

  ::field{name="extendedTheme" type="VinicuncaExtends"}
  Defaults to `{}`. Only `keyframes` and string-form `animation`; other theme tokens belong on the UnoCSS `theme` option. See [Theme](/unocss-preset/getting-started/theme).
  ::

::

## Nested presets

::field-group

  ::field{name="wind4" type="boolean | PresetWind4Options"}
  Defaults to `{ preflights: { reset: false } }`. Enables [presetWind4](https://unocss.dev/presets/wind4). `false` turns it off. `true` enables Wind4 with its own defaults (including its reset).
  ::

  ::field{name="icons" type="boolean | IconsOptions"}
  Defaults to `true`. Enables [presetIcons](https://unocss.dev/presets/icons). Pass an object for collections, extra properties, and scale.
  ::

  ::field{name="webFonts" type="boolean | WebFontsOptions"}
  Defaults to `false`. Enables [presetWebFonts](https://unocss.dev/presets/web-fonts). This preset does not set a provider; UnoCSS's own default applies.
  ::

  ::field{name="typography" type="boolean | TypographyOptions"}
  Defaults to `false`. Enables [presetTypography](https://unocss.dev/presets/typography).
  ::

  ::field{name="scrollbar" type="boolean | UnoPresetScrollbarOption"}
  Defaults to `false`. Enables the [scrollbar preset](/unocss-preset/scrollbar). Nested defaults are documented there (`noCompatible: true`, `varPrefix: ''`, …).
  ::

  ::field{name="magicCss" type="boolean"}
  Defaults to `false`. Enables the [Magic CSS](/unocss-preset/magic-css) animation preset. There is no extra options object.
  ::

  ::field{name="animation" type="boolean | AnimationOptions"}
  Defaults to `true`. Enables [enter/exit animations](/unocss-preset/animations). When you pass an object, `unit` defaults to `'ms'`. See nested fields below.
  ::

  ::field{name="fluid" type="boolean | DeepPartial<FluidOptions>"}
  Defaults to `true`. Enables [fluid sizing](/unocss-preset/fluid). Nested defaults: `prefix: 'fluid-'`, `minContainerWidth: 320`, `maxContainerWidth: 1920`, `defaultBaseUnit: 'px'`.
  ::

::

### AnimationOptions

Used when `animation` is an object. These become the default CSS for `animate-in` / `animate-out`. Duration is **not** read from `theme.duration.DEFAULT`.

::field-group

  ::field{name="unit" type="'ms' | 's'"}
  Defaults to `'ms'`. Unit for `duration` and `delay`.
  ::

  ::field{name="duration" type="number"}
  No default. When omitted, `animate-in` / `animate-out` hardcode `animation-duration: 150ms`. When set, the value is concatenated with `unit`.
  ::

  ::field{name="delay" type="number"}
  No default. Default `animation-delay`.
  ::

  ::field{name="direction" type="'alternate' | 'alternate-reverse' | 'normal' | 'reverse'"}
  No default. Default `animation-direction`.
  ::

  ::field{name="fillMode" type="'backwards' | 'both' | 'forwards' | 'none'"}
  No default. Default `animation-fill-mode`.
  ::

  ::field{name="iterationCount" type="'infinite' | number"}
  No default. Default `animation-iteration-count`.
  ::

  ::field{name="playState" type="'paused' | 'running'"}
  No default. Default `animation-play-state`.
  ::

  ::field{name="timingFunction" type="'ease' | 'ease-in' | 'ease-in-out' | 'ease-out' | 'linear' | string"}
  No default. Default `animation-timing-function`.
  ::

::

### FluidOptions

Used when `fluid` is an object. See [Fluid](/unocss-preset/fluid) for utilities.

::field-group

  ::field{name="minContainerWidth" type="number"}
  Defaults to `320`. Viewport width (in the base unit count) where scaling starts.
  ::

  ::field{name="maxContainerWidth" type="number"}
  Defaults to `1920`. Viewport width where scaling stops.
  ::

  ::field{name="defaultBaseUnit" type="'px' | 'rem' | 'em' | 'vw' | 'vh' | 'vmin' | 'vmax' | 'fr' | 'percent'"}
  Defaults to `'px'`. Unit multiplied into min/max sizes. `'percent'` emits `%`.
  ::

  ::field{name="prefix" type="string"}
  Defaults to `'fluid-'`. Prefix for utilities and custom properties. The fluid README still shows `f-`; that is not the default.
  ::

  ::field{name="expandCSSVariables" type="boolean"}
  Defaults to `false`. When `true`, the clamp is split into intermediate custom properties (`range-width`, `factor`, `range-size`, `fluid`, `size`).
  ::

  ::field{name="disableTheme" type="boolean"}
  Defaults to `false`. Disables named theme shortcuts (`fluid-p-lg`, `fluid-text-sm`, …).
  ::

  ::field{name="themeShortcuts" type="boolean"}
  Defaults to `true`. Set `false` to keep numeric utilities but skip named shortcuts.
  ::

  ::field{name="attributify" type="boolean"}
  Defaults to `false`. Adds extra shortcuts such as `pt-fluid-32/64` for attributify-style names.
  ::

  ::field{name="commentHelpers" type="boolean"}
  Defaults to `false`. Accepted by the type; the current preset does not emit CSS comments.
  ::

  ::field{name="utilities" type="Array<[string, string[]]>"}
  Defaults to `[]`. Extra `[name, cssProperties]` pairs merged ahead of the built-in list. A name that matches a built-in replaces it.
  ::

::

### UnoPresetScrollbarOption

Used when `scrollbar` is an object. See [Scrollbar](/unocss-preset/scrollbar).

::field-group

  ::field{name="scrollbarWidth" type="string"}
  Defaults to `'8px'`.
  ::

  ::field{name="scrollbarHeight" type="string"}
  Defaults to `'8px'`.
  ::

  ::field{name="scrollbarTrackRadius" type="string"}
  Defaults to `'4px'`.
  ::

  ::field{name="scrollbarThumbRadius" type="string"}
  Defaults to `'4px'`.
  ::

  ::field{name="scrollbarTrackColor" type="string"}
  Defaults to `'#f5f5f5'`.
  ::

  ::field{name="scrollbarThumbColor" type="string"}
  Defaults to `'#ddd'`.
  ::

  ::field{name="prefix" type="string | string[]"}
  Defaults to `''`. Applied to utilities and shortcuts.
  ::

  ::field{name="varPrefix" type="string"}
  Defaults to `''`. CSS variables are `--scrollbar-*` (not `--un-scrollbar-*`) unless you set a prefix.
  ::

  ::field{name="numberToUnit" type="(value: number) => string"}
  Defaults to a function that divides by 4 and appends `rem` (`scrollbar-w-4` → `1rem`). Used when a size class ends in a unitless number.
  ::

  ::field{name="noCompatible" type="boolean"}
  Defaults to `true`. Skip Firefox `scrollbar-color` / `scrollbar-width` (except `scrollbar-width: none`). Set `false` to emit those properties; rounded corners and `scrollbar-w` / `scrollbar-h` then have no effect in Firefox because `scrollbar-color` disables `::-webkit-scrollbar` styling.
  ::

::

## Transformers

::field-group

  ::field{name="directives" type="boolean | TransformerDirectivesOptions"}
  Defaults to `true`. [transformerDirectives](https://unocss.dev/transformers/directives).
  ::

  ::field{name="variantGroup" type="boolean | TransformerVariantGroupOptions"}
  Defaults to `true`. [transformerVariantGroup](https://unocss.dev/transformers/variant-group).
  ::

  ::field{name="alias" type="boolean | TransformerAliasOptions"}
  Defaults to off (`undefined`). Opt-in transformer that expands shortcut aliases in source. See below.
  ::

::

### TransformerAliasOptions

Enable with `alias: true` or an options object. The transformer looks up names in your UnoCSS `shortcuts` and replaces prefixed tokens in source.

```ts [uno.config.ts]
export default defineConfig({
  shortcuts: {
    btn: 'px-4 py-2 rounded bg-primary text-inverted'
  },
  presets: [
    presetVinicunca({
      alias: true
    })
  ]
})
```

```html
<div class="*btn"></div>
<!-- becomes: px-4 py-2 rounded bg-primary text-inverted -->

<div class="+btn"></div>
<!-- becomes: btn px-4 py-2 rounded bg-primary text-inverted
     and `btn` is added to the UnoCSS blocklist when keep.block is true -->
```

::field-group

  ::field{name="prefix" type="string"}
  Defaults to `'*'`. Prefix that **replaces** the alias with the expanded shortcut.
  ::

  ::field{name="keep" type="string | KeepOption"}
  Defaults to `'+'`. Prefix that **keeps** the original class and appends the expansion. A string is treated as `{ prefix, block: true }`.
  ::

::

`KeepOption`:

::field-group

  ::field{name="prefix" type="string"}
  Defaults to `'+'`. Keep prefix.
  ::

  ::field{name="block" type="boolean"}
  Defaults to `true`. When `true`, the original alias name is added to `uno.config.blocklist` so it is not generated as its own utility.
  ::

::
