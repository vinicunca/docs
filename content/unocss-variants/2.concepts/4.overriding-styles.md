---
title: Overriding styles
description: Append extra classes at the call site with class or className. Nothing is dropped from the recipe.
---

## Single component

Pass `class` or `className` when you call the recipe. Both keys are equivalent; `uv` concatenates them after the recipe classes.

::code-preview{class="[&>div]:*:my-0"}

:::uv-button
---
as: button
color: secondary
class: bg-pink-500 hover:bg-pink-500
uv:
  base: font-semibold text-white py-1 px-3 rounded-full active:opacity-80
  variants:
    color:
      primary: bg-blue-500 hover:bg-blue-700
      secondary: bg-purple-500 hover:bg-purple-700
      success: bg-green-500 hover:bg-green-700
      error: bg-red-500 hover:bg-red-700
---
Button
:::

::

```ts
import { uv } from 'unocss-variants'

const button = uv({
  base: 'font-semibold text-white py-1 px-3 rounded-full active:opacity-80',
  variants: {
    color: {
      primary: 'bg-blue-500 hover:bg-blue-700',
      secondary: 'bg-purple-500 hover:bg-purple-700',
      success: 'bg-green-500 hover:bg-green-700',
      error: 'bg-red-500 hover:bg-red-700'
    }
  }
})

button({
  color: 'secondary',
  class: 'bg-pink-500 hover:bg-pink-500'
})
// font-semibold text-white py-1 px-3 rounded-full active:opacity-80 bg-purple-500 hover:bg-purple-700 bg-pink-500 hover:bg-pink-500
```

The secondary background is still in the string. To make pink win, prefix the override (or the variant) with `uno-layer-uv:` — see [Layers](/unocss-variants/concepts/layers).

```ts
uv({ base: 'px-4 py-2 rounded' })({ class: 'px-2 py-4 rounded-lg' })
// px-4 py-2 rounded px-2 py-4 rounded-lg
```

## Slots

Pass overrides to the slot function you want to change:

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

:::uv-slot-card
---
styles:
  base: dark:bg-purple-800 bg-purple-100
  name: dark:text-purple-200 text-purple-500
  role: dark:text-purple-100
---
:::

::

```vue
<script setup>
const { base, avatar, wrapper, description, infoWrapper, name, role } = card()
</script>

<template>
  <figure :class="base({ class: 'bg-purple-100 dark:bg-purple-800' })">
    <img :class="avatar()" src="/images/intro-avatar.png" alt="">
    <div :class="wrapper()">
      <!-- ... -->
      <div :class="name({ class: 'text-purple-500 dark:text-purple-200' })">
        Ketut Gabler
      </div>
      <div :class="role({ class: 'dark:text-purple-100' })">
        Full-stack developer
      </div>
    </div>
  </figure>
</template>
```

```ts
base({ class: 'bg-purple-100 dark:bg-purple-800' })
// md:flex bg-background-muted rounded-xl p-8 md:p-0 bg-purple-100 dark:bg-purple-800

name({ class: 'text-purple-500 dark:text-purple-200' })
// text-sm text-sky-500 dark:text-sky-400 text-purple-500 dark:text-purple-200
```

Do not rely on `card({ class: '...' }).base()` — the root `class` is not applied to slots on the published 1.5.0 build. Call `base({ class: '...' })` instead.
