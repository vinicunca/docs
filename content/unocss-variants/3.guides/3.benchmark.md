---
title: Benchmark
description: How the unocss-variants repository is wired to time uv. No throughput numbers are published here.
---

The package.json at v1.5.0 defines:

```json
{
  "scripts": {
    "benchmark": "pnpm build && node benchmark/run.mjs"
  }
}
```

Run it from a clone of [`unocss-variants`](https://github.com/praburangki/unocss-variants):

```bash
pnpm benchmark
```

That script is supposed to build `dist/` with tsdown, then execute `benchmark/run.mjs`.

::warning
At committed HEAD `b0936f1` (`chore: release v1.5.0`), **`benchmark/run.mjs` is not in the repository** — there is no `benchmark/` tree in git. The npm script will fail until those files exist. Do not treat any third-party timing tables as results for this package.
::

When the runner is present, use it to compare local changes. Do not paste unpublished numbers into docs or issues as if they were official.
