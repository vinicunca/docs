This guide walks you through turning a fresh Windows machine into a web development workstation. Your code, tools and terminal run inside a real Linux distribution through the Windows Subsystem for Linux (WSL), while your editor, browser and everyday apps stay on Windows.

## Who it's for

- Web developers on Windows who want the same tooling as macOS and Linux teammates (POSIX shell, `curl | sh` installers, Linux-only npm packages).
- Anyone setting up a new machine, or cleaning up an old one, to work on Vinicunca projects or any Node.js, Vue or Nuxt codebase.

You need Windows 11 (or Windows 10 version 22H2) with virtualization enabled in the firmware, and an account with administrator rights.

::note
Some steps use features that only exist on newer builds: `sudo` for Windows needs Windows 11 version 24H2, and mirrored WSL networking needs Windows 11 version 22H2. Check yours with :kbd{value="Win"} + :kbd{value="R"}, then run `winver`.
::

## What you'll end up with

- **Windows Terminal** as the default terminal, opening straight into your Linux home directory.
- **WinGet** (and optionally Chocolatey) to install and update Windows apps from the command line.
- **WSL 2** with Ubuntu, systemd enabled and sensible memory and networking settings.
- **zsh** with Oh My Zsh (or Starship) as your login shell.
- **Git** that signs in through Git Credential Manager or the GitHub CLI, with no passwords stored in plain text.
- **Node.js** LTS managed by fnm, switching versions per project automatically.
- **pnpm** as your package manager.
- **VS Code** connected to WSL, linting and formatting with the Vinicunca ESLint config.

## Steps

Follow the pages in order. Each one assumes the previous ones are done.

::card-group

:::card{title="1. Windows Terminal" icon="i-simple-icons-windowsterminal" to="/windows-dev/guide/terminal"}
Install or update Windows Terminal and make it the default.
:::

:::card{title="2. Package managers" icon="i-lucide-package" to="/windows-dev/guide/package-managers"}
Open an admin shell, then use WinGet (and optionally Chocolatey) to install apps.
:::

:::card{title="3. WSL" icon="i-simple-icons-linux" to="/windows-dev/guide/wsl"}
Install Ubuntu on WSL 2 and configure memory, networking and systemd.
:::

:::card{title="4. zsh" icon="i-simple-icons-zsh" to="/windows-dev/guide/zsh"}
Replace bash with zsh, Oh My Zsh and a couple of essential plugins.
:::

:::card{title="5. Git" icon="i-simple-icons-git" to="/windows-dev/guide/git"}
Configure your identity, line endings and secure authentication.
:::

:::card{title="6. Node.js" icon="i-simple-icons-nodedotjs" to="/windows-dev/guide/nodejs"}
Install fnm inside WSL and use it to install Node.js LTS.
:::

:::card{title="7. pnpm" icon="i-simple-icons-pnpm" to="/windows-dev/guide/pnpm"}
Install pnpm with its standalone script.
:::

:::card{title="8. VS Code" icon="i-simple-icons-visualstudiocode" to="/windows-dev/guide/vscode"}
Connect VS Code to WSL and set up ESLint, Vue and UnoCSS.
:::

::

## Time estimate

Plan for about **45 to 60 minutes** on a reasonable internet connection. Installing WSL requires one reboot, and most of the remaining time is spent waiting for downloads.
