Installing apps from the command line is faster than clicking through installers, and it makes a new machine reproducible. Windows has two popular options:

- **[WinGet](https://learn.microsoft.com/en-us/windows/package-manager/winget/)** is Microsoft's package manager. It's preinstalled on Windows 11 and modern Windows 10 as part of App Installer, so start here.
- **[Chocolatey](https://community.chocolatey.org/)** is a community package manager with a larger catalog. It's optional; install it only if WinGet doesn't have something you need.

## Open an administrator shell

Some installers need administrator rights. Pick whichever method suits you.

::tabs

:::tabs-item{label="Terminal (Admin)" icon="i-lucide-shield"}
Press :kbd{value="Win"} + :kbd{value="X"} (or right-click the Start button) and select **Terminal (Admin)**. Accept the User Account Control prompt; the tab title starts with **Administrator:**.

![Right-clicked Start button menu](/images/start-menu.png)
:::

:::tabs-item{label="sudo" icon="i-lucide-terminal"}
On Windows 11 version 24H2 and later you can elevate a single command from a normal PowerShell tab with [Sudo for Windows](https://learn.microsoft.com/en-us/windows/advanced-settings/sudo/).

Enable it once in **Settings** › **System** › **Advanced** › **Enable sudo**, then prefix any command:

```powershell
sudo winget install --id Git.Git -e
```

The default **In a new window** mode is the safest; the inline modes let other processes in the same console drive the elevated one.
:::

:::tabs-item{label="Always elevated profile" icon="i-lucide-shield-check"}
In Windows Terminal, open **Settings** › **Profiles** › **Windows PowerShell** and turn on **Run this profile as Administrator**. That profile then always opens elevated, so keep your everyday profile (Ubuntu) unelevated.

![Run this profile as Administrator toggle](/images/new-admin.jpg)
:::

::

::warning
Only elevate when an installer asks for it. Never run your WSL shell, `pnpm` or `npm` as administrator.
::

## WinGet

Check that WinGet is available:

```powershell
winget --version
```

If the command isn't recognized, update **App Installer** from the Microsoft Store.

The commands you'll use most:

```powershell
# Find a package and its ID
winget search vscode

# Install by exact ID
winget install --id Microsoft.VisualStudioCode -e

# List installed apps and available updates
winget list
winget upgrade

# Update everything
winget upgrade --all

# Remove an app
winget uninstall --id Microsoft.VisualStudioCode -e
```

`--id` with `-e` (`--exact`) avoids installing a similarly named package by accident. Browse IDs on [winget.run](https://winget.run) or with `winget search`.

## Chocolatey (optional)

::steps{level="3"}

### Open an administrator PowerShell

Use one of the methods above. Chocolatey's default install and most of its commands need an elevated shell.

### Check the execution policy

```powershell
Get-ExecutionPolicy
```

If it returns `Restricted`, allow scripts for this session only:

```powershell
Set-ExecutionPolicy Bypass -Scope Process
```

### Run the installer

Review [install.ps1](https://community.chocolatey.org/install.ps1) first if you like, then run:

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
```

### Verify

Open a new admin tab and run `choco -?`. See [Getting Started](https://docs.chocolatey.org/en-us/getting-started) for more.

::

Basic commands, all run from an administrator shell:

```powershell
choco install <package> -y
choco upgrade <package>
choco upgrade all -y
choco list
choco uninstall <package>
```

Search the [Community Package Repository](https://community.chocolatey.org/packages) for package names.

## Recommended apps

A few free apps that are useful for web development on Windows:

- [Microsoft PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/) is a set of power-user utilities, including the [Command Palette](https://learn.microsoft.com/en-us/windows/powertoys/command-palette/overview) launcher (:kbd{value="Win"} + :kbd{value="Alt"} + :kbd{value="Space"}), FancyZones window layouts and a color picker. PowerToys Run is still included if you prefer the older launcher.
- [Git for Windows](https://gitforwindows.org/) provides Git Credential Manager, which the [Git step](/windows-dev/guide/git) uses from WSL.
- [GitHub Desktop](https://desktop.github.com/) is a graphical Git client.
- [RunJS](https://runjs.app/) is a JavaScript and TypeScript scratchpad.
- [Bruno](https://www.usebruno.com/) and [Postman](https://www.postman.com/) are API clients.
- [Figma](https://www.figma.com/) is a collaborative UI design tool.
- [draw.io](https://www.drawio.com/) is a diagramming app.
- [Obsidian](https://obsidian.md/) and [Notion](https://www.notion.com/) are note-taking apps.

Install them in one go:

::code-group

```powershell [WinGet]
winget install -e --id Microsoft.PowerToys
winget install -e --id Git.Git
winget install -e --id GitHub.GitHubDesktop
winget install -e --id lukehaas.RunJS
winget install -e --id Bruno.Bruno
winget install -e --id Postman.Postman
winget install -e --id Figma.Figma
winget install -e --id JGraph.Draw
winget install -e --id Obsidian.Obsidian
winget install -e --id Notion.Notion
```

```powershell [Chocolatey]
choco install powertoys git github-desktop runjs postman figma drawio obsidian notion -y
```

::
