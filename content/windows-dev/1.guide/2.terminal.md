[Windows Terminal](https://learn.microsoft.com/en-us/windows/terminal/) is Microsoft's modern terminal app. It gives you tabs, split panes, themes, a command palette and per-profile settings, and it automatically creates a profile for every WSL distribution and PowerShell version you install.

## Install

Windows 11 ships with Windows Terminal and updates it through the Microsoft Store. On Windows 10, or if you removed it, install it with WinGet from PowerShell:

```powershell
winget install --id Microsoft.WindowsTerminal -e
```

You can also get it from the [Microsoft Store](https://apps.microsoft.com/detail/9n0dx20hk701) or the [GitHub releases page](https://github.com/microsoft/terminal/releases). Builds from GitHub don't update automatically.

## Make it the default terminal

Windows 11 version 22H2 and later already use Windows Terminal as the default terminal application. To check, or to set it on Windows 10:

::steps{level="3"}

### Open the settings

Press :kbd{value="Ctrl"} + :kbd{value=","}, or select the `˅` dropdown next to the tabs and choose **Settings**.

![Windows Terminal dropdown menu with Settings](/images/term-settings.jpg)

### Pick Windows Terminal

In **Startup**, set **Default terminal application** to **Windows Terminal**, then select **Save**.

::

From now on, anything that opens a console window, including PowerShell, Command Prompt and WSL, opens in Windows Terminal.

## Open WSL by default

::note
Do this after you install WSL in the [WSL step](/windows-dev/guide/wsl). Windows Terminal adds an **Ubuntu** profile automatically once the distribution exists.
::

::steps{level="3"}

### Set Ubuntu as the default profile

In **Startup**, set **Default profile** to **Ubuntu**.

![Startup settings with Ubuntu as the default profile](/images/default-profile.jpg)

### Start in your Linux home directory

Open **Profiles** › **Ubuntu** › **General** and set **Starting directory** to `~`.

If your Terminal version doesn't accept `~`, leave the starting directory empty and change **Command line** instead:

```powershell
wsl.exe -d Ubuntu --cd ~
```

![Ubuntu profile with the command line and starting directory settings](/images/start-dir.jpg)

::

New tabs now open zsh (or bash, until you reach the [zsh step](/windows-dev/guide/zsh)) in `/home/<your-user>` instead of `/mnt/c/Users/<you>`.

## Useful shortcuts

| Action | Shortcut |
| --- | --- |
| New tab with the default profile | :kbd{value="Ctrl"} + :kbd{value="Shift"} + :kbd{value="T"} |
| Command palette | :kbd{value="Ctrl"} + :kbd{value="Shift"} + :kbd{value="P"} |
| Split the current pane | :kbd{value="Alt"} + :kbd{value="Shift"} + :kbd{value="D"} |
| Open `settings.json` | Hold :kbd{value="Shift"} while selecting **Settings** |

Everything in the settings UI is also stored in `settings.json`, so you can back it up or copy it to another machine. Color schemes, fonts and key bindings are covered in the [Windows Terminal customization docs](https://learn.microsoft.com/en-us/windows/terminal/customize-settings/appearance).
