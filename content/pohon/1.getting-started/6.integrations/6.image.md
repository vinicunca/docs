## Installation

To get started, you can follow the official [guide](https://image.nuxt.com/get-started/installation) or in summary:

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/image
```

```bash [yarn]
yarn add @nuxt/image
```

```bash [npm]
npm install @nuxt/image
```

```bash [bun]
bun add @nuxt/image
```

::

Then, add the `@nuxt/image` module in your `nuxt.config.ts`:

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: [
    'pohon-ui',
    '@nuxt/image'
  ],
  css: ['~/assets/css/main.css']
});
```

## Usage

When `@nuxt/image` is installed, Pohon UI renders the [`<NuxtImg>`](https://image.nuxt.com/usage/nuxt-img) component instead of the native `img` tag in the following components:

- [Avatar](/pohon/components/avatar)
- [BlogPost](/pohon/components/blog-post)
- [ChangelogVersion](/pohon/components/changelog-version)
- [ColorModeImage](/pohon/components/color-mode-image)
- [ProseImg](/pohon/typography/images-and-embeds)

There is nothing else to configure. Any `<NuxtImg>` prop you pass to these components, like `format`, `quality` or `provider`, is forwarded to it:

```vue
<template>
  <PAvatar
    src="/avatar.png"
    format="webp"
  />

  <PBlogPost
    title="Introducing Nuxt Image"
    :image="{ src: '/blog/nuxt-image.png', format: 'webp', quality: 80 }"
  />
</template>
```

::note{to="https://image.nuxt.com/get-started/configuration#domains" target="_blank"}
Remote images are only optimized when their host is listed in the `image.domains` option of your `nuxt.config.ts`.
::

::tip
The Avatar passes its size as `width` and `height`, so `<NuxtImg>` requests an image that matches the rendered size.
::

### Opt-out

To render a native `img` tag on a single Avatar, use the `as` prop:

```vue
<template>
  <PAvatar
    src="https://github.com/benjamincanac.png"
    :as="{ img: 'img' }"
  />
</template>
```
