Akar is an open-source library of unstyled, accessible Vue primitives. Use the parts as the foundation of a design system, or adopt them one component at a time.

It is a 1:1 fork of [Reka UI](https://reka-ui.com) (itself descended from [Radix Vue](https://www.radix-vue.com/)), published as the `akar` package. Component names match Reka's (`AccordionRoot`, `DialogTrigger`, no prefix). Style them with whatever CSS you already use.

## Principles

### Accessibility first

Components follow [WAI-ARIA design patterns](https://www.w3.org/WAI/ARIA/apg/). Akar handles aria attributes, keyboard navigation, and focus management so you can concentrate on layout and visuals.

### Unstyled and open

Nothing ships with opinions about color, spacing, or typography. Wrap, extend, or restyle every part. See the [styling](/akar/guides/styling) and [composition](/akar/guides/composition) guides.

### Controlled or uncontrolled

Primitives work uncontrolled out of the box (`defaultValue`) and accept `v-model` when you need to own the state. See [controlled state](/akar/guides/controlled-state).

### Predictable API

Every part that renders a DOM node accepts `as` / `asChild`. The library is fully typed and tree-shaken: unused components do not land in the bundle.
