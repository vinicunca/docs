## FieldControl

[Source](https://github.com/vinicunca/akar/blob/1c7a9cb424cb223b73bb75816fc5f0706f618963/packages/core/src/Field/FieldControl.vue)

### Props

- **id** — `string | undefined; optional`: Id of the element. Falls back to the id generated by the ancestor \`FieldRoot\`.
- **modelValue** — `string | number | undefined; optional; default: undefined`: The controlled value of the control. Can be bound with \`v-model\`.
- **defaultValue** — `string | number | undefined; optional; default: undefined`: The value of the control when it is initially rendered. Use when you do not need to control its value.
- **asChild** — `boolean | undefined; optional`: Change the default rendered element for the one passed as a child, merging their props and behavior.  Read our [Composition](https://akar.vinicunca.dev/docs/guides/composition) guide for more details.
- **as** — `AsTag | Component | undefined; optional; default: "input"`: The element or component this component should render as. Can be overwritten by \`asChild\`.

- **default** — `{}`

### Events

- **update:modelValue** — `[value: string]`

## FieldError

[Source](https://github.com/vinicunca/akar/blob/1c7a9cb424cb223b73bb75816fc5f0706f618963/packages/core/src/Field/FieldError.vue)

### Props

- **id** — `string | undefined; optional`: Id of the element. Auto-generated when not provided.
- **match** — `boolean | keyof ValidityState | undefined; optional; default: undefined`: Restricts when this error renders: - a \`ValidityState\` key (e.g. \`"valueMissing"\`) — renders when that constraint fails. - \`true\` — always renders, letting an external library control visibility. - omitted — renders whenever the field is invalid.
- **forceMount** — `boolean | undefined; optional`: Used to force mounting when more control is needed. Useful when controlling animation with Vue animation libraries.
- **asChild** — `boolean | undefined; optional`: Change the default rendered element for the one passed as a child, merging their props and behavior.  Read our [Composition](https://akar.vinicunca.dev/docs/guides/composition) guide for more details.

## FieldLabel

[Source](https://github.com/vinicunca/akar/blob/1c7a9cb424cb223b73bb75816fc5f0706f618963/packages/core/src/Field/FieldLabel.vue)

### Props

- **nativeLabel** — `boolean | undefined; optional; default: true`: Whether the label renders a native \`label\` element. Set to \`false\` when rendering another element (e.g. \`as="div"\`): it then drops \`for\`, focuses the control on click, and relies on the control's \`aria-labelledby\`.  Useful for button controls like \`SelectTrigger\`, where a native label would forward clicks and \`:hover\` to the button.
- **for** — `string | undefined; optional`: The id of the element the label is associated with.
- **asChild** — `boolean | undefined; optional`: Change the default rendered element for the one passed as a child, merging their props and behavior.  Read our [Composition](https://akar.vinicunca.dev/docs/guides/composition) guide for more details.
- **as** — `AsTag | Component | undefined; optional`: The element or component this component should render as. Can be overwritten by \`asChild\`.

## FieldRoot

[Source](https://github.com/vinicunca/akar/blob/1c7a9cb424cb223b73bb75816fc5f0706f618963/packages/core/src/Field/FieldRoot.vue)

### Props

- **name** — `string | undefined; optional`: The name of the field. Submitted with its owning form as part of a name/value pair, and used to match server \`errors\` on a \`FormRoot\`. Takes precedence over the \`name\` of the control.
- **disabled** — `boolean | undefined; optional`: When \`true\`, prevents the user from interacting with the field's control. Takes precedence over the \`disabled\` of the control.
- **required** — `boolean | undefined; optional`: When \`true\`, indicates that the user must set the value before the owning form can be submitted.
- **invalid** — `boolean | undefined; optional; default: undefined`: When \`true\`, marks the field invalid regardless of its own validation. Useful when the field state is controlled by an external library.
- **dirty** — `boolean | undefined; optional; default: undefined`: Whether the field's value has changed from its initial value. Useful when the field state is controlled by an external library.
- **touched** — `boolean | undefined; optional; default: undefined`: Whether the field has been touched (its control blurred). Useful when the field state is controlled by an external library.
- **validate** — `FieldValidateFn | undefined; optional`: Custom validation function. Return an error message (or array of messages) when invalid, or \`null\`/\`undefined\` when valid. Receives the control's value and the values of every named field in the owning form.  Can be async, but an async \`validate\` does not prevent form submission when \`validationMode\` is \`onSubmit\`.
- **validationMode** — `FieldValidationMode | undefined; optional; default: undefined`: When the field (re-)runs validation. Takes precedence over the \`validationMode\` of an ancestor \`FormRoot\`. - \`onSubmit\`: when the form is submitted, then on every change after that. - \`onBlur\`: when the control loses focus. - \`onChange\`: on every change to the control's value.
- **validationDebounceTime** — `number | undefined; optional`: How long to wait (in ms) between \`validate\` calls when validating on change.
- **asChild** — `boolean | undefined; optional`: Change the default rendered element for the one passed as a child, merging their props and behavior.  Read our [Composition](https://akar.vinicunca.dev/docs/guides/composition) guide for more details.
- **as** — `AsTag | Component | undefined; optional`: The element or component this component should render as. Can be overwritten by \`asChild\`.

### Slots

- **default** — `{ invalid: boolean; errors: string[]; }`

### Events

No events are declared.
