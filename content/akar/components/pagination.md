## PaginationRoot

[Source](https://github.com/vinicunca/akar/blob/1c7a9cb424cb223b73bb75816fc5f0706f618963/packages/core/src/Pagination/PaginationRoot.vue)

### Props

- **page** — `number | undefined; optional`: The controlled value of the current page. Can be binded as \`v-model:page\`.
- **defaultPage** — `number | undefined; optional; default: 1`: The value of the page that should be active when initially rendered.  Use when you do not need to control the value state.
- **itemsPerPage** — `number; required`: Number of items per page
- **total** — `number | undefined; optional; default: 0`: Number of items in your list
- **siblingCount** — `number | undefined; optional; default: 2`: Number of sibling should be shown around the current page
- **disabled** — `boolean | undefined; optional`: When \`true\`, prevents the user from interacting with item
- **showEdges** — `boolean | undefined; optional; default: false`: When \`true\`, always show first page, last page, and ellipsis
- **asChild** — `boolean | undefined; optional`: Change the default rendered element for the one passed as a child, merging their props and behavior.  Read our [Composition](https://akar.vinicunca.dev/docs/guides/composition) guide for more details.
- **as** — `AsTag | Component | undefined; optional; default: "nav"`: The element or component this component should render as. Can be overwritten by \`asChild\`.

### Slots

- **default** — `{ page: number; pageCount: number; }`

### Events

- **update:page** — `[value: number]`
