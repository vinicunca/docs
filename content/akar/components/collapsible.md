## CollapsibleRoot

[Source](https://github.com/vinicunca/akar/blob/1c7a9cb424cb223b73bb75816fc5f0706f618963/packages/core/src/Collapsible/CollapsibleRoot.vue)

### Props

- **defaultOpen** — `boolean | undefined; optional; default: false`: The open state of the collapsible when it is initially rendered. <br> Use when you do not need to control its open state.
- **open** — `boolean | undefined; optional; default: undefined`: The controlled open state of the collapsible. Can be binded with \`v-model\`.
- **disabled** — `boolean | undefined; optional`: When \`true\`, prevents the user from interacting with the collapsible.
- **unmountOnHide** — `boolean | undefined; optional; default: true`: When \`true\`, the element will be unmounted on closed state.
- **asChild** — `boolean | undefined; optional`: Change the default rendered element for the one passed as a child, merging their props and behavior.  Read our [Composition](https://akar.vinicunca.dev/docs/guides/composition) guide for more details.
- **as** — `AsTag | Component | undefined; optional`: The element or component this component should render as. Can be overwritten by \`asChild\`.

### Slots

- **default** — `{ open: boolean; }`

### Events

- **update:open** — `[value: boolean]`
