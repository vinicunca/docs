Low-level helpers used by the primitives and by your own wrappers.

::card-group

:::card{title="Config Provider" icon="i-lucide-wrench" to="/akar/utilities/config-provider"}
Wraps your app to provide global configurations.
:::

:::card{title="Focus Scope" icon="i-lucide-wrench" to="/akar/utilities/focus-scope"}
Manages focus within a component boundary with support for trapping and looping focus navigation.
:::

:::card{title="Presence" icon="i-lucide-wrench" to="/akar/utilities/presence"}
Manages mounting and unmounting of element with transition support.
:::

:::card{title="Primitive" icon="i-lucide-wrench" to="/akar/utilities/primitive"}
Compose Akar's functionality onto alternative element types or your own Vue components.
:::

:::card{title="Roving Focus" icon="i-lucide-wrench" to="/akar/utilities/roving-focus"}
Utility component that implements the roving tabindex method to manage focus between items.
:::

:::card{title="Slot" icon="i-lucide-wrench" to="/akar/utilities/slot"}
Merges its props onto its immediate child.
:::

:::card{title="useDateFormatter" icon="i-lucide-wrench" to="/akar/utilities/use-date-formatter"}
Creates a wrapper around the `DateFormatter`, which is an improved version of the Intl.DateTimeFormat API, that is used internally by the various date builders to easily format dates in a consistent way.
:::

:::card{title="useDirection" icon="i-lucide-wrench" to="/akar/utilities/use-direction"}
Access the current direction
:::

:::card{title="useEmitAsProps" icon="i-lucide-wrench" to="/akar/utilities/use-emit-as-props"}
Convert emits into object similar to props
:::

:::card{title="useFilter" icon="i-lucide-wrench" to="/akar/utilities/use-filter"}
Locale-Aware string filtering
:::

:::card{title="useForwardExpose" icon="i-lucide-wrench" to="/akar/utilities/use-forward-expose"}
Forward component's exposed value, props and $el.
:::

:::card{title="useForwardPropsEmits" icon="i-lucide-wrench" to="/akar/utilities/use-forward-props-emits"}
Combinations for useForwardProps & useEmitAsProps
:::

:::card{title="useForwardProps" icon="i-lucide-wrench" to="/akar/utilities/use-forward-props"}
Forward component's props without boolean casting
:::

:::card{title="useId" icon="i-lucide-wrench" to="/akar/utilities/use-id"}
Generate random id
:::

:::card{title="useLocale" icon="i-lucide-wrench" to="/akar/utilities/use-locale"}
Access the current locale
:::

:::card{title="Visually Hidden" icon="i-lucide-wrench" to="/akar/utilities/visually-hidden"}
Hides content from the screen in an accessible way.
:::
