Akar provides accessible Vue primitives for dialogs, menus, forms, calendars, and other interface patterns. It handles interaction and accessibility while leaving visual styling to your application.

## Start here

- [Install Akar](/akar/getting-started) in a Vue or Nuxt project.
- Browse the [component reference](/akar/components) for props, slots, and events generated from the tagged source.
- Read the [Dialog guide](/akar/guides/dialog) for a complete component anatomy example.

The component reference is generated from the same tagged Vue files as the released package. Each page links to its source commit.
